# Exploratory Data Analysis (EDA)

## Project Overview
This project explores a sample student dataset using Python.

## Tools and Libraries
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Dataset inspection and statistical summary
- Missing value and duplicate checks
- Correlation between study hours and marks
- Scatter plot, histogram, and bar chart
- Summary statistics and conclusion

## Key Findings
- Average marks: 63.5
- Average attendance: 79.5%
- Correlation between study hours and marks: 0.983

## Note
The dataset contains 8 artificially created student records.
The findings apply only to this sample and should not be
generalized to real students.
